# Mettaton-EX-Proyecto-Sintesis-8A---Adptado-a-tematica-OMS-
Proyecto para la clase de Robotica, publicado el 27/3/2026, como proyecto de robotica, tratando de integrar el tema de Hambre cero, decidi tomar fuerte inspiracion del juego Undertale (2015). El juego como tal dura menos de 3 minutos, pero tomo medio mes para desarrollar, fue creado en la plataforma ide.mblock.cc hace 7 meses.

Instrucciones:
Disparar a las cajas rectangulares blanco y negro, las blancas no pueden ser disparadas por si solo, se debe usar las bombas que son disparables, esto creara una "explosion" en forma de cruz, dara mas daño. Cada 4 o 3 segundos, no importando mas cuanto daño has tenido, tu HP sera incrementado por 1. La pelea no dura tanto tiempo (menos de 4 minutos). Si el HP llega a menos de 0, el juego se denomina perdido.

Controles:
Arriba = ↑
Abajo = ↓
Derecha = →
Izquierda = ←
Disparar = Z
Arriba Lento = ↑ + x
Abajo Lento = ↓ + x
Derecha  Lento = → + x
Izquierda Lento = ← + x
Nota: No es posible jugar con controles de consola (PS, Xbox, Nintendo etc.) dado a que solo sirve desde un teclado.

Sistema de Daño:
Ataque de piernas (Izquierda y Derecha) = -1HP
Rayos = -1HP
Cajas Rompibles  = -1HP
Cajas Blancas = -1HP
Bomba (no explotada) = -1HP
Explocion de Bomba = -3HP
